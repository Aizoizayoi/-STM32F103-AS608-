使用到的器件： STM32F103C8开发板、AS608指纹模块、USB转TTL刷机板、ST-Link烧录器

功能：串口输入1、2、3、4，分别对应指纹录入、指纹匹配、指纹删除和退出程序的功能。
1.	指纹录入：分别录两次指纹，判断是否一致然后存入指纹库的指定位置，可存入1024个指纹；有超时和5次不匹配返回菜单机制。若按下后始终不抬起，等待约15s后返回主菜单。
2.	指纹匹配：在指纹库中搜索是否有匹配的指纹，如有则返回匹配分数和成功提示，不成功提示失败并返回主菜单。有超时退出机制。
3．删除指纹：删除指纹库指定位置的指纹。可修改成删除指定范围内所有的指纹。
4. 退出程序：串口若30s未输入指令，则会自动退出程序。

主要思路：使用串口进行菜单显示，用硬件触发USART，并用中断进行接收和超时判断。先配置AS608的USART，也是硬件触发+中断接收。封装发送和接收字符，然后再封装发送和接收字符串。然后根据AS608的发送和接受格式，再封装包头、地址、包标识的发送，用其拼接每个指令的发送，指令函数主要返还应答的结果，用于调试和判断。主函数中再用指令拼接录入、匹配和删除功能。最后用一个函数，用状态机的方式进行功能判断，处理失败、超时等情况。
